## 规则与源文件核验

- 16 项 Node 核心测试通过。用 200 场相同种子的战斗覆盖主线、高塔、首领和演武，并让十一人全部参与。12,518 个行动、18,728 个命中、15,436 次随机调用、672 次手动必杀和 200 次结算均与开工提交逐项一致。 [核对报告](同种子战斗对照.json)
- 开工时已有的 PNG、MP3 与 MP4 校验值一致。备用魔导星典保持为未引用素材。 [既有媒体 SHA-256](既有媒体SHA256.json)

## 复跑

需 Node、Playwright 和 Chrome。在项目根目录运行，按本机设置 `NODE_PATH`，可通过 `CHROME_PATH` 或 `--chrome` 指定 Chrome。浏览器脚本默认传入 `--mute-audio`。

```powershell
node --test tests/core.cjs
node tests/browser.cjs --domain-cinema --case desktop,retina,mobile,file,power,canvas --out "$env:TEMP/sky-wave8-cinema"
node tests/browser.cjs --case desktop,file
```
