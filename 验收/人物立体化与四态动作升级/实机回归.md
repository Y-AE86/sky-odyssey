# 人物立体光影、四态动作与首屏提速验收

2026-11-28 · 开工提交 `11493c9` · `dev/sky-odyssey`

## 战斗实测

- 十一位星灵与四种反派在实际战斗阵容中入镜。浮空星港用冷星蓝轮廓光，齿轮云巅用暖金，星穹祭坛用淡紫。光沿迎光侧的半透明边缘过渡，脚踝处压暗约 12.5%。站立时脚底坐标固定，柔摆幅度从小腿往上渐增。
- 墨姬与冰灵均在实战观察到站立、蓄力、出招、受击及收势回站，普攻与必杀共用出招图，近战残影也使用该图。用每张图的鞋底与眼线归一体高，同一阵位四态的眼线到鞋底分别为约 94.52 和 90.83 CSS 像素。蓄力约 90 毫秒，受击姿态约 240 毫秒，白闪比例为 71%。
- 桌面截图中，墨姬冲刺时脚底离地 14.6 CSS 像素，影子留在起跳地面，宽度和不透明度相对站立降至约 86% 和 79%。回落后脚下出现淡紫尘环。序列帧退场 160 毫秒后仍可见 18 颗紫色余烬，有约 340 毫秒渐隐尾韵。
- 省电和 Canvas2D 保留四态与原有战斗流程，使用轻量绘制。六组均核对战后特效清理与退场画布移除。桌面另跑上轮特效专项，命中帧与数字仍同步，镜头和余烬均回收。该次活跃特效段约 60.3 fps，供同机复查。

六组 Chrome 均使用 `--mute-audio`。页面异常、错误级控制台日志、HTTP 404 和意外资源失败均为 0。

- 桌面分别扣住主脚本、海报与 Pixi 请求，确认静态载入提示可单独显示，主城磁贴在海报解码前可见，战斗准备页也可见。22 张主城次要图像采用异步解码。
- 六组首次交互前均未请求 Pixi 或背景音乐。主视频先单独挂载，备用视频在主视频已实际播放 0.800–0.810 秒且缓冲足够时才登记 `metadata` 源。首次真实点击后音频才解锁并请求背景乐。备用视频的实际下载量取决于浏览器的媒体缓冲策略。
- Chrome 限速横屏另测主城、图鉴、养成和召唤。限速为 300 毫秒往返延迟、200 KB/s 下行，主城磁贴 DOM 约 2.24 秒出现，图鉴、养成和召唤停留时均未请求 Pixi。iOS Safari 真机的首次冷启动、系统静音策略和视频缓冲行为待实机复核。

- 桌面全流程另外通过主城、养成、抽卡、航线、实际战斗结算、旧档导入导出及两章画面切换。全程静音，错误与资源失败为 0。

- 以 `11493c9` 所含文件为基准，482 个 PNG、4 个 MP3、29 个 MP4 均通过 SHA-256 验证，包含六张新动作原图。[开工媒体 SHA-256](开工媒体SHA256.json)

## 复跑

浏览器脚本使用本机已安装的 Playwright 和 Chrome，可通过 `CHROME_PATH` 或 `--chrome` 指定 Chrome。浏览器启动参数内置 `--mute-audio`。

```powershell
node --test tests/core.cjs
node tests/browser.cjs --actor-upgrade --case desktop,retina,mobile,file,power,canvas --out 验收复跑
node tests/browser.cjs --vfx-upgrade --case desktop
node tests/browser.cjs --case desktop
```
