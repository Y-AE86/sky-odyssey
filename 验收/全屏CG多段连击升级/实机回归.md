# 全屏 CG 多段连击升级实机验收

2026-11-28，Windows Chrome 158.0.8127.89 无头运行，所有 Chrome 实例均传入 `--mute-audio`。通过游戏内角色肖像触发真实必杀。测试仅设置初始阵容、血量和怒气，命中由引擎实际生成。敌方镜像在星环演武交叉验证。

## 整数、血条和中断对账

| h08 | e0 | 16 + 17 + 20 + 21 + 22 + 43 | 139 | 3987 → 3970 → 3950 → 3929 → 3907 → 3864 | 3864 |

| h08 | e2 | 16 + 17 + 20 + 21 + 22 + 43 | 139 | 4484 → 4467 → 4447 → 4426 → 4404 → 4361 | 4361 |

逐项比较 DOM 的每一次 HITS 和总伤害更新、舞台实际血条以及引擎原始命中。h08 三个目标的每一拍错开 0 / 35 / 70 ms。轻击无冲击波、色散及长顿帧，终结同时触发冲击波、色散及 72 ms 顿帧。合成子击期间盾、怒气和状态保持原值，诅咒、削甲和冰冻随真实事件提交。

- h08 双目标 12 HITS，分别结算 137 / 143 点。h01 攻击 7 HP 目标时，最后一段落到 0 HP，累计 7 段各 1 点。
- h01 全盾保留 3 次格挡与 3 次反伤，总伤计数无更新。部分盾只提交一次反伤。
- 屏蔽首次媒体帧回调后，已启动的 h01 CG 自动切回 3 次真实命中和九格。另在 0.527 秒停住 h01 CG，已有 2 段播出，剩余伤害和状态同帧按原事件补齐。
- h08 中途跳过时，已呈现 3 段，剩余 3 个目标快照静默提交一次。结算场景与引擎状态一致，视频节点离开 DOM。
- 敌方 h08 以镜像视频向左释放，18 段对账通过，离场立即回收 Pixi 与视频。

## 复跑

在仓库根目录使用已安装 Playwright 的 Node 环境。可通过 `--chrome` 指定本机 Chrome。

```powershell
node --test tests/core.cjs
node tests/browser.cjs --domain-cinema --case desktop,retina,mobile,speed2,speed3,file,power,canvas --chrome "C:\Program Files\Google\Chrome\Application\chrome.exe" --out "验收复跑/cg-multihit"
```
