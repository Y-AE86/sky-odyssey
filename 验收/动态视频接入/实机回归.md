## 复跑

安装 Playwright 和 Chrome 后，在项目根目录运行。

```powershell
node tests/browser.cjs --chrome "C:\Program Files\Google\Chrome\Application\chrome.exe" --case desktop,retina,mobile,file --out "验收复跑"
```
