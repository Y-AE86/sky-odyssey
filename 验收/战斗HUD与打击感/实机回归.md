## 弹道、状态与打击时序

- 六种普攻均采样到实际飞行中的 ADD 贴图。双方弹道朝向与移动方向一致。原受击火花在伤害数字出现的同帧绘制。护盾和冰封位于单位前景，诅咒与治疗位于脚底层。实测法阵纵向透视 0.36，内层纹理持续转动。四种状态均观察到退场阶段。

- 六位主力的黑底九格均按真实原图与 418×418 的帧边界核对。墨姬三次和薇尔四次峰值逐段命中。霜华对六个对手的局部冰爆间隔保持 80 游戏毫秒。艾莉娅只给前三个阵位套盾。莉莉丝切真实后排并触发吸血。尾击纹理系数为 1.45。普通接触使用 43 游戏毫秒顿帧，暴击和尾击使用 72 游戏毫秒。省电模式未发出手绘特效图请求，镜头缩放为 1、顿帧为 0。

## 复跑

在项目根目录运行，环境需能解析 Playwright，或通过 `NODE_PATH` 指向已有安装。Chrome 路径和输出目录按本机实际位置填写。

~~~powershell
$chrome = "$env:ProgramFiles\Google\Chrome\Application\chrome.exe"
node --test tests/core.cjs
node tests/browser.cjs --chrome $chrome --case desktop,retina,mobile,file --out "$env:TEMP\sky-hud-broad"
node tests/browser.cjs --chrome $chrome --hud-only --case desktop,retina,mobile,file --out "$env:TEMP\sky-hud-focus"
node tests/browser.cjs --chrome $chrome --vfx-only --case desktop,retina,mobile,file --out "$env:TEMP\sky-hud-vfx"
~~~
