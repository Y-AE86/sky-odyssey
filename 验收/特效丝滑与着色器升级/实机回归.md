实测渲染设备为 `ANGLE (Intel, Intel(R) UHD Graphics 770 (0x00004680) Direct3D11 vs_5_0 ps_5_0, D3D11)`。桌面战斗特效活跃段为 58.9 fps，四组正常画质活跃段为 20.3–58.9 fps。 60fps 是正常画质渲染目标，报告记录的是本机实际帧间隔。浏览器使用 `--mute-audio`，手机横屏为模拟，留出左 44、右 35 CSS 像素安全区。六组页面、控制台和资源错误均为 0。

双帧使用 ADD 混合并共享位置、锚点和染色。逻辑帧、命中数字与图集命中仍同一绘制帧出现。折射窗口 260 毫秒，色散窗口 100 毫秒，叠加时使用一次渲染通道。色散峰值 4.2 CSS 像素。折射处理镜头内的角色与特效，空气环也可在背后的场景画面上看到。血条、飘字和 HUD 单独绘制。余烬共用一张 24×24 Canvas 纹理，在图集结束后保留约 500 毫秒。结算和离场会释放滤镜与粒子。省电及禁用 WebGL 的流程均完成结算。

BOSS 受击画面的固定身体采样区内，三色通道均达到 220 的像素由 8,742 降至 2,974。同帧滤镜开关对照中，固定右上 HUD 采样区的像素一致。图集保留原有 418×418 格坐标，实际绘制排除格内透明区。固定画面换回完整纹理格时，比较的 921,600 个画布像素中，最大单通道差为 2 / 255。[像素对照](像素对照.json)

同随机种对照 200 场战斗、11,968 个行动、16,866 次命中和 13,740 次随机调用，逐项一致。开工的 490 个媒体文件逐项复核 SHA-256，涵盖上一轮的 453 个媒体文件与此后归档的 37 张截图。[同种子战斗对照](同种子战斗对照.json) · [媒体指纹](既有媒体SHA256.json)
