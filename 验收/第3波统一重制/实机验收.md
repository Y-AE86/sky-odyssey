桌面运行在 AMD Radeon RX 9070 XT。横屏手机用 Chrome 模拟 844×390、DPR 3，左右安全区分别为 44 和 35 CSS 像素。测试还覆盖竖屏提示、手机弹层遮罩和画框两侧背景。

主城净屏和挂机领菜、全队共鸣升级、一键配装、六人换位、单抽与十连、星穹试炼、存档导入导出及刷新均通过。首关经过正常回合结算，另走自动、手动必杀、倍速、跳过和战败流程。[桌面首关结算](desktop-result.png) · [手机首关结算](mobile-result.png)

所有模式均对照开工时的 86 张 PNG 指纹。HTTP 入口逐张比对原图响应和本地文件的 SHA-256，双击入口逐张解码测尺寸并校验 6 个离线 Q 版条目的 SHA-256。浏览器控制台错误、资源加载失败和 HTTP 错误均为零，空视频清单全程产生零 MP4 请求。[原图指纹](原图指纹.json) · [离线实测](file-report.json) · [临时副本补图实测](replacement-report.json)

另一份报告记录临时副本中的动态看板、必杀视频以及高清 PNG 回退。[视频实测](视频实测报告.json)

## 复跑

安装 Playwright 与 Chrome 后，在项目根目录用 PowerShell 执行。

```powershell
node tests/browser.cjs --chrome "C:\Program Files\Google\Chrome\Application\chrome.exe" --baseline "验收/第3波统一重制/原图指纹.json" --case desktop,retina,mobile,file,1080p,qhd,4k,replacement --out "验收复跑"
```
