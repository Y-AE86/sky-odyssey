## 复跑

安装 Playwright 和 Chrome 后，在项目根目录运行。

```powershell
node --test tests/core.cjs
node tests/browser.cjs --chrome "C:\Program Files\Google\Chrome\Application\chrome.exe" --case desktop,retina,mobile,file --baseline "验收/第5波猩红月蚀/原图指纹.json" --out "验收复跑"
```

指纹清单对应本轮完成回归时的 99 张 PNG。工作区继续加入素材后，可省略 `--baseline` 及其文件参数，按当前图片列表复跑。
