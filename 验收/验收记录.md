# 《浮空星途》第 1 波美术接入验收

2026-11-27 · dev/sky-odyssey · Antigravity 逐屏复验

桌面从本地 HTTP 打开、离线双击项目根目录的 `index.html` 都能玩到战后结算。35 件本波组件均在可操作的游戏界面解码显示。八份运行记录和 45 张原始浏览器截图收在本目录。

## 逐屏复验

| 页面 | 打开后可核对的内容 |

## 实测数据

Windows Chrome 静音无头运行，显卡为 Intel UHD 770。每组均完成含 12 个单位的手动必杀与自然结算，检查 WebGL 真实缓冲区、抗锯齿、高性能偏好、线性采样与 mipmap。fps 为两个战斗窗口的实测值。

桌面特写实测 853 毫秒，同次三连击的累计伤害依次为 239 → 488 → 730。4K 保留原生 3840 × 2160 渲染，在这台集显上低于 60 fps。海报细节以原稿 1672 × 941 为上限。

手机横屏海报及场景铺满 844 × 390 的视口，16∶9 操作区保留模拟的左 44、右 35 CSS 像素安全区。主城、养成、召唤、十连、航线、战斗、试炼两侧的像素采样均有图像细节。手机数据来自 Chrome 模拟。双击测试直接打开同一份本地 HTML，并检查运行期间的网络请求。

回归从新档实际操作了存档导入导出、看板与净屏、挂机、养成、编队、两池召唤、两次十连、1–1 战斗与试炼。另外通过导入测试存档展示四种 UR 星装，并以低等级挑战高塔第 30 层实测败北。

## 原图与测试复跑

项目内共有 80 张 PNG（含预留图与透明标记）。逐张与本波开工快照、初始提交的字节核对一致。HTTP 响应校验逐张核对原始文件哈希，双击入口核对图片天然尺寸与三张内置 Q 版纹理的原始字节。后补 h04 图的 HTTP 和双击测试均在临时副本中运行。[原图 SHA-256](原图指纹.json)　[替换原图实测](replacement-report.json)

仓库内 15 个 JS / CJS 文件通过语法检查。13 项核心测试覆盖首次十连、跨池旧档迁移、重复碎片、保底概率、六人编队、八种必杀、十关与三试炼结算。旧档缺少首次十连记录时，升级后的第一次十连同样享有保障。星露、星尘与体力瓶收在背包材料图鉴中，既有资源和消耗规则照旧。

在项目根目录可复跑核心测试。完整浏览器测试需要 Node、Playwright 和本机 Chrome。

```powershell
node --test tests/core.cjs
node tests/browser.cjs --chrome "C:\Program Files\Google\Chrome\Application\chrome.exe" --case desktop,retina,mobile,file,1080p,qhd,4k,replacement --baseline "验收/原图指纹.json" --out "验收复跑"
```
