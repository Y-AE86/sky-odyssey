## 原图与复跑

HTTP 实测逐张比对原图响应字节。双击入口逐张解码校验像素尺寸，进战时再载入六张内置 Q 版，其 Base64 还原字节的 SHA-256 与 PNG 原图逐一吻合。临时副本中改尺寸补图后，HTTP 使用新 Pixi 纹理，双击入口使用原生图片随战场定位。以后替换同尺寸的内置 Q 版，应同步更新 `js/offline-textures.js`，以便离线 WebGL 读取新版字节。[离线实测](file-report.json) · [补图实测](replacement-report.json)

另在双击入口单独模拟首次纹理包缺失，场上真身随即改用本地原图，下一战自动重试并恢复全部 12 个 Pixi 单位。只损坏艾莉娅的一条打包纹理时，敌我两名艾莉娅均显示 862×1138 的原始 PNG，其余十人继续由 Pixi 渲染，战斗正常结算。加载时连点跳过也只发奖一次。必杀解码期间离场并导入新存档，旧特写和奖励均未写回。上述故障在测试会话内注入，独立于表中的正常回归。

15 个脚本语法检查、14 项核心测试通过。已安装 Playwright 和 Chrome 后，在项目根目录用 PowerShell 复跑。

```powershell
node --test tests/core.cjs
node tests/browser.cjs --chrome "C:\Program Files\Google\Chrome\Application\chrome.exe" --baseline "验收/原图指纹.json" --case desktop,retina,mobile,file,1080p,qhd,4k,replacement --out "验收复跑"
```
