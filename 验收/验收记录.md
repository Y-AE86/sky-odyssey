2026-11-27 · dev/sky-odyssey · 原画归档版本 201f185

## 实测结果

Windows Chrome 静音无头，显卡为 Intel UHD 770。每组均检查了原生 DPR 的 WebGL 缓冲区、12 个战斗单位和 8 张纹理，并完成实战、手动必杀和自然结算。帧率为两个实战窗口的采样。

| 入口与视口 | DPR | 画布物理像素 | 最低文字对比度 | 实测 fps | 错误 / 失败总数 | 运行记录 |
| --- | ---: | --- | ---: | --- | ---: | --- |
| 1280×720 桌面 | 1 | 1280 × 720 | 11.46∶1 | 59.2 / 60 | 0 | [报告](desktop-report.json) |
| 1440×900 大屏 | 2 | 2880 × 1620 | 11.46∶1 | 59.7 / 59.9 | 0 | [报告](retina-report.json) |
| 844×390 横屏手机模拟 | 3 | 2079 × 1170 | 6.87∶1 | 41.7 / 60 | 0 | [报告](mobile-report.json) |
| 双击入口 1280×720 | 1 | 1280 × 720 | 11.46∶1 | 59.6 / 60.1 | 0 | [报告](file-report.json) |
| 1920×1080 | 1 | 1920 × 1080 | 11.35∶1 | 59.9 / 59.6 | 0 | [报告](1080p-report.json) |
| 2560×1440 | 1 | 2560 × 1440 | 11.34∶1 | 50.5 / 54 | 0 | [报告](qhd-report.json) |
| 3840×2160 | 1 | 3840 × 2160 | 6.86∶1 | 29.3 / 36.4 | 0 | [报告](4k-report.json) |

每组对主城标题、副标题、试炼卡与头图共 18 项文字状态做采样。浏览器临时隐藏字形，在实际字框内逐像素读取合成后的原画和渐层，再按 sRGB 相对亮度计算对比度。七组最低为 6.86∶1，横屏手机「可领取　11,520 星币」实测 6.87∶1。

844 × 390、DPR 3 模拟机保留左 44、右 35 CSS 像素安全区。主城通用弹窗、编队弹窗、十连与战后结算的遮罩实测均从 (0, 0) 覆盖至 (844, 390)。在原 16∶9 舞台两侧连续取像素，四层相邻像素色差的第 90 百分位最高为 1.67 / 255。手机数据来自浏览器模拟。[边界采样](mobile-report.json)

桌面必杀海报实测 853 毫秒，三段伤害累计 256 → 504 → 729。原生 4K 采用 3840 × 2160 帧缓冲，这台集显在该分辨率下低于 60 fps。

## 原图和复跑

86 张 PNG（含补图占位）逐字节核对 `201f185`，6 张横幅还与 `raw_art/banners/` 原稿逐张匹配。HTTP 验收逐张比较响应字节，双击验收检查原始解码尺寸及三张内置 Q 版纹理字节。另在临时副本中验证了补图的 HTTP / 双击加载。[全量原图指纹](原图指纹.json)　[补图实测](replacement-report.json)

15 个 JS / CJS 文件通过语法检查，13 项核心测试全部通过。在已安装 Playwright 和 Chrome 的环境，从项目根目录运行。

```powershell
node --test tests/core.cjs
node tests/browser.cjs --chrome "C:\Program Files\Google\Chrome\Application\chrome.exe" --baseline "验收/原图指纹.json" --case desktop,retina,mobile,file,1080p,qhd,4k,replacement --out "验收复跑"
```
