# 《浮空星途》V1.0 工程验收

2026-11-27 · 交接给 Antigravity

正式入口为 `C:\Users\EDY\.gemini\antigravity\scratch\sky-odyssey\index.html`。双击可玩，也可在该目录提供本地 HTTP 静态服务。游戏使用本机提供的 PixiJS 7.4.3。浏览器运行时只访问本项目资源。

## 已交付

主城三张看板可切换、点击对话、净屏和收星匣。八位星灵支持全队共鸣、升星、四格星装、编队和阵营羁绊。常驻与 UP 池分别累计保底。两章十关、三十层高塔、天城首领、星环演武均接入同一战斗引擎，按实际结果发奖。

新档赠送六位满编队、30 张唤星券、4800 星钻和初始装备。通用等级、编队、装备、碎片、推图、试炼、抽卡保底与设置保存在 `sky_odyssey_save_v1`。HTTP 和双击入口的进度可通过设置中的 JSON 导入导出转移。

## 原图与渲染

- 开工前和交付后逐张核对 SHA-256，26 张输入 PNG 全部一致。本地 HTTP 返回字节逐张与源文件匹配。三张首发 Q 版在双击模式使用同一批 PNG 的原字节数据供 WebGL 读取，测试亦逐张核验了字节。完整清单见[原图指纹](原图指纹.json)。
- 舞台采用 16∶9 宽高比、实际容器宽度排版与系统安全区。模拟手机实际启用了左 44、右 35 CSS 像素安全区，并测试了竖屏提示和继续浏览。大屏 CSS 舞台为 1440 × 810，上下各留 45 CSS 像素。
- Pixi 使用原生 DPR、自动密度、抗锯齿、高性能偏好、mipmap 与线性过滤。默认打开呼吸、流光和完整粒子。玩家可手动开启省电静态。4K 下文字、矢量及画布按实际像素绘制，海报的细节上限是原稿的 1672 × 941。

另在同一个 Chrome 窗口，以相同随机种子交替完成四场 4K 全画质战斗。优化前两场为 41.5、42.2 fps，优化后为 43.3、43.4 fps。此集显的 4K 实战未稳定达到 60 fps。优化复用脚影，并减少血条和受击闪白的重复绘制。

桌面实战手动点按幽冥墨姬满怒卡，测得海报持续 853 毫秒，随后同次必杀总伤害依次为 241 → 489 → 710。首场自然结算，另外验证了倍速、自动、跳过、手动施放、再进入下一关及三个试炼的奖励。

从主城入口实测了看板、对白、净屏、挂机领取、福利、活动、商店、图鉴、背包、阵营筛选、共鸣、装备、换位、单抽与十连。实际下载了 JSON 存档，在文件选择器重新导入，验证非法存档被拒绝及刷新后进度一致。

另从交付用启动页进入正式双击入口，在横屏手机模拟下打开、关闭省电模式，按下一键配装与一键强化。四件装备均升至 +1，星币从 6000 扣至 5620。桌面多段命中测试另行检查飘字边界，确认同一次必杀的各段数字没有互相覆盖。

## Node 核心测试

全部运行脚本与测试脚本通过语法检查，12 组逻辑测试通过。其中包括四阵营 18% 克制、前后排目标、八种必杀、治疗护盾与反射、手动持怒、自然结算与跳过一致、首通防重复、十关可通关、三试炼真实奖励、七日活动与整套强化的扣费一致性。抽卡测试覆盖 10 抽与 60 抽双保底，以及固定种子的 60,000 次独立概率抽样。

在项目目录运行 `node --test tests/core.cjs` 即可复跑逻辑。已安装 Playwright 的环境可运行 `node tests/browser.cjs --chrome "C:\Program Files\Google\Chrome\Application\chrome.exe" --out 验收复跑`，脚本会起临时回环 HTTP 服务，也会检查真实双击入口。可用 `--case replacement` 在临时副本中复查补图，用 `--case 1080p,qhd,4k` 复查大屏。

## 后续补图

h04–h08 当前为阵营剪影和徽记。将正式海报、头像、Q 版按现有同名路径覆盖，刷新即可。以 h04 为例，对应 `assets/posters/lobby_cg_h04.png`、`assets/avatars/avatar_h04.png` 和 `assets/chibi/chibi_h04.png`。五个 Q 版空位放有 1 × 1 透明标记，启动时只读取尺寸判定是否已补图。未补图时实际送入 GPU 的是 1024 × 1280 独立矢量形象。

内置阵容在 HTTP 和双击入口都使用 Pixi 纹理。后续补进来的本地新 PNG 在双击入口使用同步动作的原生图片层，HTTP 入口直接使用新图的 Pixi 纹理。两个入口都在独立副本中测试过同名替换，证据见[补图测试](replacement-report.json)。世界地图按 `assets/scenes/bg_worldmap.png` 替换，本命武装按 `assets/weapons/weapon_hXX.png` 替换。
